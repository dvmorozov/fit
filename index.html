Fit

Interactive curve fitting for Linux, Windows and macOS

View on GitHub

An interactive curve-fitting application. You load a data set, place curves on it, and the app fits them — one peak or a hundred, by hand or fully automatically.

Written in Free Pascal with Lazarus. It runs on Linux, Windows and macOS.

Automatic decomposition

One command, Fit → Automatically, turns a raw profile into a small set of curves. It adds a background curve when the model has none and seeds a curve on every point of every peak. It then removes curves one at a time for as long as the fit stays within the accuracy you set, the maximum acceptable R-factor. What is left is the fewest curves that accuracy allows, fitted together with the background over the profile as measured, which it never rewrites. You don't guess the number of curves or tune a penalty weight. On the two-peak sample that ships with Fit, 32 starting curves come down to 3 in well under a minute.

Data from where it is published

File → New Project from Data Source finds a data set in a public repository, downloads the file you choose, shows a preview and starts a project from it, without leaving the program. No account is needed, and nothing is sent anywhere except the request itself.

Published data (DOI) takes a DOI or words. A DOI such as 10.5281/zenodo.4892237 (X-ray diffraction scans of Arabian sands) goes straight to that record's files. Words such as calcite XRD search Zenodo and figshare together for datasets, and only datasets holding a file Fit can read are listed, each with its repository, date and the size of those files.

Data catalog needs nothing typed: it lists the kinds of file this build reads — PANalytical .xrdml scans, GSAS files, tables, workbooks, archives — and opening one lists the newest datasets on both repositories that hold such files.

Inside a record, papers, pictures and files nothing here reads are left out. A .zip, .gz or .tar opens like a folder and lists the readable files in it. For a table with several columns of numbers, the preview lets you choose which one is plotted against the first.

What it does not do: it searches two repositories, Zenodo and figshare, a page at a time (25 records from Zenodo, 10 from figshare). A dataset is listed for the names of its files, so whether a .csv is a measurement or a list of references is seen in the preview, before anything becomes a project. It fetches data and nothing else — it does not identify a substance or interpret what it downloads. Every request is written to the log, and when a repository cannot be reached the other one's results are still shown, with a line saying which failed and why.

A project embeds its data, so once it is made, fitting and reopening need no network at all. Sources are contributed through one RegisterDataSource line — the registry is on the extension points page.

In every download

  • Published data (DOI): a DOI, or words to search Zenodo and figshare
  • Data catalog: the same repositories, browsed by kind of file
  • any web address
  • the sample files installed with Fit

Files it reads

  • columns of numbers: .dat, .xy, .txt
  • tables: .csv, .tsv; workbooks: .xlsx, .ods (first sheet)
  • powder patterns: .xrdml, .uxd, GSAS .gsa/.fxye, powder .cif, .xye, .chi
  • inside .zip, .gz, .tar, .tgz

Download

Built by CI from the sources in this repository. On macOS, build it yourself: one script produces Fit.app and installs it.

Each link above serves the latest release · all releases

Fit is two programs: the desktop client, which has no fitting engine of its own, and the compute server it talks to over HTTP. Every installed Fit starts the server itself — the Windows shortcut, the Linux fit command and Fit.app all launch through a wrapper that starts a server on port 8787 when nothing answers there, and reuses one that does. The portable Linux archive is the exception: start fit_server before the client.

Building from source covers the script, the macOS bundle and a Lazarus IDE walkthrough with exact versions.

For developers

Fit is a framework as much as an application: a new curve type, data loader, optimiser or whole analysis vertical is added by registration, with no framework file changed. The developers' pages hold the architecture, the extension points and the how-tos, generated from the build itself.

Test data

A sample data set ships inside every download, under Data/, and is offered by name under File → New Project from Data Source. Separately: test_data.zip.
